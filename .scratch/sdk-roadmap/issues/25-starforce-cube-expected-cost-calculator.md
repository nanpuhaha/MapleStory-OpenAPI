# 25: 스타포스 및 큐브 확률/기댓값 계산 엔진 (Expected Cost Calculator)

**What to build:**
넥슨 공식 확률표와 강화 비용 수식을 내장하여, 목표 스타포스 수치(예: 17성 -> 22성, 스타캐치/샤이닝 스타포스/파괴방지 옵션 포함)와 목표 큐브 잠재 등급/옵션 달성에 필요한 메소 및 큐브 개수의 기댓값, 표준편차, 비용 구간별 누적 달성 확률을 계산하는 순수 도메인 계산기를 제공합니다.

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

- [ ] 스타포스 강화 비용 수식(장비 레벨 및 현재 스타포스 단계별 공식) 및 성공/실패/하락/파괴 전이 행렬(Markov Chain) 기반 기댓값 모델 구현
- [ ] 스타포스 이벤트 옵션(스타캐치 5%, 1+1 이벤트, 샤이닝 스타포스 30% 할인 등) 및 파괴방지 적용 기능 구현
- [ ] 잠재능력 큐브 등급업(레어->에픽->유니크->레전드리) 및 목표 옵션 달성 기댓값 계산 모델 구현
- [ ] 입력 파라미터에 따른 평균 소요 비용, 기댓값, 상위 10%/50%/90% 컷오프 비용을 산출하는 단위 테스트 작성 및 통과
